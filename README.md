
# Distance Finder

## Description
 This program finds the distance between two positions of (x1, y1) and (x2. x2).

## How to Run

1. Open the program.
2. Run the program.
3. Enter the required values.


## Input Needed
Put in the values of (x1, y1) and (x2, y2).

## Sample Output
Ex: The distance between (x1, y1) and (x2, y2) is 2.0
